# 阈值与告警决策（全部可配）

所有阈值都可以从**三处**覆盖，优先级从低到高：代码默认 → 配置 JSON / 模板 JSON → CLI 参数。

---

## 1. 阈值清单

| 阈值 | 默认 | 含义 | 触发后的结论 |
|---|---|---|---|
| `psi_threshold` | 0.1 | PSI 观察线 | >0.1：模型分分布开始漂移，列入观察 |
| `psi_alert_threshold` | 0.25 | PSI 告警线 | >0.25：显著漂移，建议排查特征或重训 |
| `iv_threshold` | 0.02 | IV 入模线 | <0.02：无预测力，不入模 |
| `ks_overfit_threshold` | 0.05 | 过拟合衰减线 | train→test/oot 的 KS 绝对衰减 >0.05：疑似过拟合 |
| `ks_ok` | 0.3 | KS 优秀线 | 仅影响配色刻度，不改变计算 |
| `ks_warn` | 0.2 | KS 可用线 | 仅影响配色刻度 |

行业分档（写进报告视觉，不作为硬规则）：

| 指标 | 分档 |
|---|---|
| PSI | <0.1 稳定｜0.1~0.25 需观察｜>0.25 显著漂移 |
| IV（Siddiqi） | <0.02 无预测力｜0.02~0.1 弱｜0.1~0.3 中｜0.3~0.5 强｜>0.5 强到可疑（查泄漏） |
| KS | >0.3 优秀｜0.2~0.3 可用｜<0.2 偏弱 |

---

## 2. 覆盖方式

**方式 A：配置 JSON**（作用于指标计算与告警标记）
```json
{"psi_threshold": 0.08, "psi_alert_threshold": 0.2, "iv_threshold": 0.03}
```

**方式 B：CLI 参数**（同时作用于指标告警与 Excel 色阶刻度，优先级最高）
```bash
python generate_report.py ... --psi-ok 0.08 --psi-warn 0.2 --iv 0.03 \
        --ks-ok 0.35 --ks-warn 0.25 --ks-overfit 0.04
```

**方式 C：模板 JSON 的 `thresholds`**（只改配色刻度，不改告警逻辑）
```json
{"thresholds": {"psi_ok": 0.08, "psi_warn": 0.2, "ks_ok": 0.35, "ks_warn": 0.25}}
```

> 注意语义差异：`psi_threshold`/`psi_alert_threshold` 是**业务告警口径**（写进特征 PSI 表、稳定性判定）；
> `ks_ok`/`ks_warn` 只是**色阶刻度**（报告好不好看），改它们不会改变任何数值结论。

---

## 3. 读报告时的判读顺序

1. **总览** 看整体坏账率与样本时间跨度（跨度对不上其他分析都没有意义）
2. **建模效果统计** 看 ks / auc 的 train→test→oot 衰减是否 > `ks_overfit_threshold`
3. **PSI热力矩阵 + 特征PSI** 看是**分数整体漂移**还是**个别特征漂移**
   - 分数 PSI 大而特征 PSI 都小 → 大概率是人群结构变化
   - 某个特征 PSI 特别大 → 定位到该特征的取数链路
4. **校准度** 看 gap：预测概率与实际坏率的系统性偏离（评分卡上线前必看）
5. **单变量分析** 看 IV 与跨数据集稳定性，确认入模特征没有退化
